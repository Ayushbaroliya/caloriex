# CalorieX

A smart nutrition and diet planning application powered by AI.

## Features
- **BMI Calculator**: Calculate your Body Mass Index.
- **AI Nutritionist**: Chat with an AI to get personalized nutrition advice.
- **Diet Plan Generator**: Generate 1-day meal plans based on your stats.
- **Food Search**: Search for calorie and macro information (USDA & Indian databases).

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Backend**: Node.js, Express
- **AI**: Google Gemini API

## Deployment
Deployed on Render.
